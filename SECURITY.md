# Security Policy

## Supported versions

Security fixes are made for the latest released version of Event Box. Please update to the
newest release before reporting.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub:
[Report a vulnerability](https://github.com/JpOriginDev/event-box/security/advisories/new).

Include what you found, the affected version, and steps to reproduce. You can expect an initial
response within a few days. Once a fix is released, the report can be disclosed publicly with
credit to you, if you wish.
